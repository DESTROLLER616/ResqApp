# Create documentation

Create the documentation about all changes made in the current branch. You must to use [template](../../../docs/templates/pr-template.md) to put all changes.
The output is all the text in a codeblock in markdown format to copy it. The language of the description is in english.

# Branches

You only check the changes of the current branch that is the user, don't check any other branch.

# Exceptions

If the current branch has no changes, inform that to the user and do not do anything else.
